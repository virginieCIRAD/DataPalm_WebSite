# DataPalm WebSite
Ce répertoire contient tous les documents ressources (standard de fichier, MTA, DTA, etc...) ainsi que des liens utiles pour le bon déroulement des projets de recherche entre PalmElit et le CIRAD. Cette initiative s'inscrire dans le projet DataPalm piloté par Virginie Riou (CIRAD, UMR AGAP) &amp; Bertrand Malarthe (PalmElit).
